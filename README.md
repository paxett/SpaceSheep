# SpaceSheep

Unity-проект (Unity 6000.5.6f1, URP 2D, Input System). Основная сцена — `Assets/Scenes/SampleScene.unity`.

Помимо геймплея за овцу в проекте есть мини-игра «Ремонт корабля»: игрок диагностирует и устраняет поломки корабля в доке. Все данные этой мини-игры описываются одним ассетом — `RepairSessionData`.

# Структура ассета `RepairSessionData`

- **Файл данных:** `Assets/Resources/RepairSessionData.asset`
- **Модель данных:** `Assets/Scripts/Repair/RepairSessionData.cs` (ScriptableObject, классы `RepairFault`, `RepairBreakdown`, `RepairDiagnostic`)
- **Загрузка в рантайме:** `Resources.Load<RepairSessionData>("RepairSessionData")` в `Assets/Scripts/Repair/RepairBootstrap.cs`

Ассет состоит из двух блоков: **палитры цветов** (3 цвета) и **контента сессии** (массивы неисправностей, поломок и диагностик). Связи между сущностями задаются текстовыми ID. Редактируется ассет в Inspector в Unity; новый такой ассет создаётся через меню **Assets → Create → Space Sheep → Repair Session Data**. Правка кода для изменения данных не нужна.

## Палитра цветов

Поля `tileColor`, `outlineColor` и `progressColor` задают цвета всех графических элементов мини-игры. UI строится процедурно (заливки `Image`/`SpriteRenderer`, обводки), поэтому палитра полностью определяет цветовую схему.

| Поле | Значение по умолчанию | Назначение |
|------|-----------------------|------------|
| `tileColor` | #ff9933 — оранжевый (1, 0.6, 0.1) | **Цвет всех плиток/овалов.** Неисправности, поломки на корабле, диагностики (единая заливка); кнопка «Запустить диагностику». |
| `outlineColor` | #ffffff — белый (1, 1, 1) | **Цвет обводки выбранного элемента.** Выбранная плитка неисправности/диагностики, выбранный овал поломки. |
| `progressColor` | #993df2 — фиолетовый (0.6, 0.25, 0.95) | **Прогресс и символ диагностики.** Прогресс-бар выполнения; ромбы-маркеры на диагностируемых поломках. |

> Служебные цвета (тёмные панели, белый текст, красный таймер при остатке ≤ 10 сек, зелёный/красный акценты окон победы/поражения) в палитру не входят и заданы в коде `Assets/Scripts/Repair/RepairWindowController.cs`.

## Балансные значения для ремонтируемого корабля

| Поле | Тип | Значение по умолчанию | Описание |
|------|-----|----------------------|----------|
| `maxBreakdownsPerSession` | `int` | `3` | **n** — максимальное количество поломок на корабле в одной сессии. Из общего списка ремонтируемых поломок случайно выбирается не более n; если поломок меньше — берутся все. |
| `faultsPerBreakdown` | `int` | `2` | **m** — количество неисправностей, связанных с каждой поломкой. Для каждой выбранной поломки из её `consequenceFaultIds` случайно берётся не более m; если неисправностей меньше — берутся все. |

Случайный набор формируется при старте мини-игры и при каждом перезапуске («НАЧАТЬ ЗАНОВО»). В списке неисправностей отображаются только те, что связаны с выбранными для текущей сессии поломками; на корабль выводятся не более n овалов (по одному на поломку сессии), а у каждой поломки учитываются только выбранные m неисправностей.

## Контент сессии

Общий параметр контента — `ovalSize` (`Vector2`): размер овалов поломок в нормализованных единицах относительно размера корабля. Единый для всех поломок (все овалы одинакового размера).

### Неисправности — `faults`

Массив объектов `RepairFault` — это условия, с которыми игрок начинает шаг 1 (панель слева).

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `string` | Уникальный идентификатор, например `Н1`. |
| `displayName` | `string` | Название на панели неисправностей. |

### Поломки — `breakdowns`

Массив объектов `RepairBreakdown` — овалы на спрайте корабля, которые игрок выбирает на корабле.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `string` | Уникальный идентификатор, например `П1`. |
| `displayName` | `string` | Метка на овале корабля. |
| `shipPosition` | `Vector2` | Место локализации овала на схеме корабля в нормализованных координатах 0..1 (0,0 — низ-лево, 1,1 — верх-право). |
| `consequenceFaultIds` | `string[]` | ID неисправностей, которые может повлечь эта поломка; по ним выводятся овалы на корабле при выборе неисправности. |

### Диагностики — `diagnostics`

Массив объектов `RepairDiagnostic` — панель справа; одна из них запускается игроком для ремонта.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `string` | Уникальный идентификатор, например `Д1`. |
| `displayName` | `string` | Название на панели диагностики. |
| `duration` | `float` | Время исполнения в секундах — столько длится выполнение; на плитке показывается «ММ:СС» (5 → «00:05»). |
| `breakdownIds` | `string[]` | ID поломок, которые выявляет эта диагностика (устраняются по завершении). |

## Связи между сущностями

Связи задаются односторонне, обратные ссылки выводятся автоматически:

- **Неисправность → поломки:** поломка хранит `consequenceFaultIds` (какие неисправности она может повлечь); по ним находятся овалы поломок при выборе неисправности.
- **Поломка ↔ диагностика:** диагностика хранит `breakdownIds` (какие поломки выявляет); из этого списка вычисляются активные диагностики после выбора поломки.
